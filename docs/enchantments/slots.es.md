# Ranuras de encantamiento

Cada objeto tiene un máximo de encantamientos personalizados:

```yaml
slots:
  default: 5
  count-vanilla: false     # ¿los vanilla también ocupan ranura?
  per-group:
    armor: 4               # gana el primer grupo que coincida
  max-extra: 5             # máximo de ranuras extra con ampliadores
```

Las ranuras se aplican en los dos modos (libros, mesa, yunque, comandos y API).
